# 🧠 AI Skill Assessment System

## Description
Flask + AI-based system that generates MCQ questions based on:
- Stream
- Course
- Specialization
- Year
- Difficulty

## Features
- Dynamic course selection
- AI-generated questions using Gemini API
- Score evaluation system
- Skill analysis report

## Tech Stack
- Python
- Flask
- HTML/CSS
- JavaScript
- Gemini AI

## Note
This project uses environment variables for API keys (not included for security).
